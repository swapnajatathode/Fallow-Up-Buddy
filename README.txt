FOLLOWUP BUDDY — INSTALLABLE WEB APP PACKAGE

Files:
- index.html: app
- manifest.webmanifest: install metadata
- sw.js: offline caching
- icon-192.png and icon-512.png: app icons

IMPORTANT:
This package is not an Android APK. To install it like an app using "Add to Home screen", it must be hosted on an HTTPS website. You can use a free static hosting service such as GitHub Pages or Netlify, subject to their current terms and limits.

Quick test:
1. Open index.html in a browser on a computer to test the interface.
2. For phone installation, upload all files while preserving their names and folder structure to an HTTPS static host.
3. Open the hosted site in Chrome on Android.
4. Use Chrome's menu > Install app or Add to Home screen (the exact wording varies).
5. The app stores records in that browser on that device. Use Export backup regularly.

Privacy:
No analytics, account login, or server submission is built into this prototype. Browser storage is local to the device/browser. Do not enter sensitive information. A future hosted app should have its privacy and security reviewed before public use.
